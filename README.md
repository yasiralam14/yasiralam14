# Hi, I'm Yasir Alam

I hold a Master's degree with a specialization in Machine Learning, and I am actively focusing my work on Generative AI and building multi-agent systems. My academic and technical projects bridge advanced language model alignment, continuous latent representations, and spatial computing.

## 🔬 Core Focus Areas

* **3D Computer Vision & Novel View Synthesis (NVS):** Researching 3D reconstruction architectures. I focus on evaluating and improving 3D Gaussian Splatting and non-Gaussian primitives, particularly regarding their structural integrity at high-frequency geometric edges and depth discontinuities.
* **Energy-Based Models (EBMs) & GenAI:** Developing continuous latent variable models and non-autoregressive generative frameworks. I actively build systems that replace standard priors with expressive EBMs trained via Contrastive Divergence and Langevin MCMC.
* **Multi-Agent Systems:** Designing robust agentic architectures and orchestration engines. I build systems that operate within interactive Python REPL loops, leveraging specialized LLM endpoints for infinite context ingestion and recursive "endless thinking" to solve complex coding tasks. 
* **LLM Alignment:** Fine-tuning language models using Supervised Fine-Tuning (SFT) and Reinforcement Learning (GDPO/GRPO) to enhance reasoning and align models for specialized, multi-turn agentic behaviors.

## 🚀 Highlighted Work

* **RLM Harness:** A recursive language model multi-agent system built for automated code repair and execution. It features a specialized LLM API endpoint, intelligent repository parsing for full situational awareness, and a resilient execution pipeline with dynamic feedback loops operating inside a Python REPL.
* **State-Tracking Agentic LLMs:** A Llama-3.1-8B model aligned via SFT and GDPO to conduct structured, multi-turn interviews while maintaining a dynamic internal reasoning state.
* **Discontinuity-Aware NVS Evaluation:** My Master's thesis framework utilizing Laplacian pyramid zoning to quantify 3D rendering accuracy at sharp boundaries.
* **EBM Priors for Latent Generation:** A PyTorch implementation learning EBM priors over the latent space of generative models.
* **Hierarchical VAEs (HT-HVAE):** A two-level hierarchical architecture combining DistilBERT and GPT-2 for coherent, long-form text generation.
